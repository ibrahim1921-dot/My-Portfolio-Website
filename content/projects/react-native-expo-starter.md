# React Native Expo Starter

A fully functional multi-screen mobile app — built not from a template, but from scratch — to prove that good architecture habits carry across platforms.

## Overview

My work has always been rooted in the web, but I knew that being a well-rounded developer meant understanding mobile too. So instead of watching tutorials, I built something real: a multi-screen React Native app with proper navigation, typed components, and a structured codebase — the same standards I hold myself to on the web.

The result is a clean, extensible starter that covers every fundamental you need before building a production mobile app: routing, reusable UI, theming, and end-to-end TypeScript.

## What's Inside

- **Four connected screens** — Home, Menu, Contact, and a Modal — wired together with Expo Router's file-based navigation
- **Reusable component library** — shared UI pieces designed to be dropped into any screen without duplication
- **Consistent theming** — centralised constants and custom hooks keep the visual language uniform across the entire app
- **TypeScript throughout** — typed props, typed navigation params, typed everything — no guessing what a component expects
- **Expo Go workflow** — instant live preview on a real device with zero simulator configuration

## Tech Stack

- **React Native** — core mobile framework
- **Expo** — build toolchain and device preview
- **Expo Router** — file-based navigation (same mental model as Next.js App Router)
- **TypeScript** — type safety across components and navigation
- **ESLint** — enforced code quality and consistency

## Why This Project Matters

Shipping this app taught me something that tutorials rarely do: mobile development rewards the same discipline as good web development. Component boundaries, separation of concerns, consistent naming — these things matter just as much on a 390px screen as they do in a browser.

I can now move fluidly between a Next.js codebase and a React Native project, apply the same architectural thinking in both, and get up to speed on a mobile team without starting from zero.
