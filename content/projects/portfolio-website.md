# Portfolio Website

The site you are looking at right now — designed, built, and deployed entirely by me as a living showcase of my frontend development skills.

## Overview

A portfolio is only as good as the code behind it. Rather than reaching for a template, I built this site from scratch using Next.js and TypeScript, with a focus on performance, SEO, and maintainability. Every section — from the project cards to the blog posts — is driven by a clean content system so updates take seconds, not hours.

The result is a fast, accessible, and fully responsive site that I am genuinely proud to share with clients and employers.

## What's Inside

- **Markdown-powered blog and projects** — content lives in plain `.md` files with YAML front-matter, parsed at build time with no database required
- **Server-side rendering** — pages are pre-rendered by Next.js for fast load times and strong SEO out of the box
- **Light and dark mode** — theme switching bridged between `next-themes` and Material-UI with zero flash on load
- **Functional contact form** — messages are delivered directly to email via the Resend API
- **SEO-ready** — structured data, Open Graph tags, Twitter cards, sitemap, and robots.txt all configured
- **Fully responsive** — designed to look sharp on every screen size, from mobile to widescreen

## Tech Stack

- **Next.js 16** with App Router for server components and static generation
- **TypeScript** for type safety across every component and data layer
- **Material-UI** for a consistent, accessible component library
- **gray-matter** for Markdown parsing
- **Resend** for transactional email
- **Vercel** for deployment and hosting

## Why This Project Matters

Building your own portfolio teaches you things that client work rarely does — you own every decision, from architecture to pixel. This project pushed me to properly understand the difference between client and server rendering, design a content system that is easy to maintain long-term, and ship a polished product with real SEO and performance standards.
