# Task Management App

A full-stack productivity application — React on the frontend, Node.js and MongoDB on the backend — built to handle real user workflows around task creation, organisation, and completion.

## Overview

This project was my first time owning the entire stack end to end. I designed and built the REST API, structured the database schema, wired up authentication with JWT and Google OAuth2, and connected it all to a clean React frontend. The goal was to ship something that works the way users actually expect a task app to work — not just a CRUD demo.

## What's Inside

- **Full task lifecycle** — create, edit, complete, and delete tasks with a smooth, responsive UI
- **Secure authentication** — JWT-based sessions plus Google OAuth2 for one-click sign-in
- **RESTful API** — well-structured Express endpoints with proper status codes and error handling
- **Persistent storage** — MongoDB with schemas designed to efficiently model task and user relationships
- **Responsive design** — fully functional on mobile and desktop using Material-UI

## Tech Stack

- **Frontend** — React, Material-UI
- **Backend** — Node.js, Express
- **Database** — MongoDB
- **Authentication** — JWT, Google OAuth2

## Why This Project Matters

Most developers can build a frontend or follow a backend tutorial. Fewer can sit down, design a database schema, build an authenticated API around it, and connect it to a polished UI — all without a roadmap. This project is proof that I can do exactly that. It is the kind of end-to-end ownership that translates directly to contributing on a real product team.
